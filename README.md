# 🎮 Little Man Studio — Penugasan Three.js

Project penugasan Three.js: menampilkan model 3D **Little_Man.glb** dengan fitur interaktif.

## ✨ Fitur
- 🔄 Auto-rotate kamera
- 🕸️ Mode wireframe
- 🌙 Mode malam
- 🎉 Party lights
- 📸 Screenshot
- 🎨 Pengatur warna lampu
- 📏 Slider skala & kecepatan
- ✨ Partikel bintang + cincin neon
- 🎭 Animasi otomatis (bawaan GLB atau programatik)
